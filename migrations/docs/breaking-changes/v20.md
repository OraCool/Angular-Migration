# Angular 20 Breaking Changes

> **Zoneless Change Detection Stable, InjectFlags Removed**

## 🔴 CRITICAL Changes

### InjectFlags Removed
- **Removed**: `InjectFlags` enum from `@angular/core`
- **Impact**: Build errors if using `InjectFlags.Optional`, `InjectFlags.Self`, etc.
- **Migration**: Use `InjectOptions` object instead
- **Example**:
  ```typescript
  // Before (v19)
  import { inject, InjectFlags } from '@angular/core';
  const service = inject(MyService, InjectFlags.Optional);

  // After (v20)
  import { inject } from '@angular/core';
  const service = inject(MyService, { optional: true });
  ```

**InjectFlags Migration Map**:
- `InjectFlags.Optional` → `{ optional: true }`
- `InjectFlags.SkipSelf` → `{ skipSelf: true }`
- `InjectFlags.Self` → `{ self: true }`
- `InjectFlags.Host` → `{ host: true }`

### TypeScript 5.9+ Required
- **Required**: TypeScript `^5.9.0` or higher
- **Impact**: Build failures with older TypeScript
- **Action**: Update if not already on 5.9+

## 🟠 HIGH Severity

### Zoneless Change Detection Now Default
- **Changed**: Zoneless is now the recommended default
- **Impact**: Apps still using zone.js need to keep it explicitly
- **Migration**:
  ```typescript
  // If staying with zone.js (old behavior)
  import 'zone.js'; // Keep this import

  // If migrating to zoneless (recommended)
  export const appConfig: ApplicationConfig = {
    providers: [
      provideExperimentalZonelessChangeDetection() // Still experimental flag
    ]
  };
  ```

### provideExperimentalZonelessChangeDetection() Stable
- **Status**: API is stable (name kept for backward compatibility)
- **Benefit**: Better performance, smaller bundles (no zone.js)
- **Action**: Consider migrating from zone.js

## 🟡 MEDIUM Severity

### afterRenderEffect Behavior Changes
- **Changed**: Timing of `afterRenderEffect` may differ
- **Impact**: Race conditions if relying on exact timing
- **Action**: Review components using `afterRenderEffect`

## 🟢 LOW Severity (New Features)

### Enhanced Signal APIs
- **New**: Additional signal utilities and patterns
- **Benefit**: More ergonomic reactive programming

### Improved SSR Hydration
- **Enhancement**: Better hydration performance and reliability
- **Benefit**: Faster page loads, fewer hydration errors

### TypeScript 5.9 Features Support
- **Support**: Full support for TS 5.9 features
- **Benefit**: Better type inference, new language features

## ⚠️ Important Notes

### InjectFlags Removal Checklist
1. Search codebase for `InjectFlags` imports
2. Replace all enum usages with object options
3. Test dependency injection still works correctly
4. Update any custom injection utilities

### Zoneless Migration Checklist
1. Enable `provideExperimentalZonelessChangeDetection()`
2. Remove `zone.js` import from `polyfills.ts`
3. Update components to use signals or `ChangeDetectorRef.markForCheck()`
4. Test all async operations trigger change detection
5. Update third-party libraries if needed
