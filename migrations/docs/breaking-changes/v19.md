# Angular 19 Breaking Changes

> **TypeScript 5.9+, BrowserModule.withServerTransition Removed**

## 🔴 CRITICAL Changes

### TypeScript 5.9+ Required
- **Required**: TypeScript `^5.9.0` or higher
- **Impact**: Build failures with older TypeScript
- **Action**: Update `package.json`:
  ```json
  {
    "devDependencies": {
      "typescript": "~5.9.0"
    }
  }
  ```

### BrowserModule.withServerTransition() Removed
- **Removed**: `BrowserModule.withServerTransition()` method
- **Impact**: SSR apps will have build errors
- **Migration**: Remove the call, SSR now works automatically
- **Example**:
  ```typescript
  // Before (v18)
  @NgModule({
    imports: [
      BrowserModule.withServerTransition({ appId: 'my-app' }) // ❌ Remove
    ]
  })

  // After (v19)
  @NgModule({
    imports: [
      BrowserModule // SSR works automatically
    ]
  })
  ```

## 🟠 HIGH Severity

### Node.js 18 Support Dropped
- **Removed**: Node.js 18.x support
- **Required**: Node.js 20.17+ or 22.11+
- **Impact**: Build failures with old Node.js
- **Action**: Update Node.js version

## 🟡 MEDIUM Severity

### Zoneless Change Detection Improvements
- **Status**: Zoneless is now recommended (experimental in v18)
- **Benefit**: Better performance, no zone.js needed
- **Migration**: Use `provideExperimentalZonelessChangeDetection()`

## 🟢 LOW Severity (New Features)

### Linked Signals
- **New**: `linkedSignal()` for derived state with setter
- **Example**:
  ```typescript
  class MyComponent {
    input = signal(0);
    // Linked signal - can be set independently or computed
    derived = linkedSignal(() => this.input() * 2);

    setDerived(value: number) {
      this.derived.set(value); // Can override computation
    }
  }
  ```

### Resource API
- **New**: `resource()` for async data loading
- **Benefit**: Better than combineLatest + switchMap patterns
- **Example**:
  ```typescript
  userId = signal(1);

  userResource = resource({
    request: () => ({ id: this.userId() }),
    loader: ({ request }) => this.http.get(`/api/users/${request.id}`)
  });

  // Access in template
  // userResource.value() - current data
  // userResource.isLoading() - loading state
  ```
