# Angular 17 Breaking Changes

> **Built-in Control Flow, Deferrable Views, Legacy Material Removed**

## 🔴 CRITICAL Changes

### Material Legacy Components Removed
- **Removed**: All `@angular/material/legacy-*` imports
- **Impact**: Build errors if using legacy imports
- **Action**: Must complete MDC migration from v15
- **Migration**: `ng generate @angular/material:mdc-migration`
- **Example**:
  ```typescript
  // ❌ No longer works
  import { MatLegacyButtonModule } from '@angular/material/legacy-button';

  // ✅ Use MDC components
  import { MatButtonModule } from '@angular/material/button';
  ```

### TypeScript 5.2+ Required
- **Required**: TypeScript `^5.2.0` or higher
- **Impact**: Build failures with older TypeScript
- **Action**: Update `package.json`:
  ```json
  {
    "devDependencies": {
      "typescript": "~5.2.0"
    }
  }
  ```

## 🟠 HIGH Severity

### @angular/platform-server-init Package
- **Change**: Server initialization moved to separate package
- **Impact**: SSR apps may need updates
- **Action**: Check SSR configuration

## 🟡 MEDIUM Severity

### inject() in Module Constructors
- **Enhancement**: `inject()` can now be used in module constructors
- **Impact**: None (backward compatible)
- **Benefit**: Cleaner dependency injection

## 🟢 LOW Severity (New Features)

### Built-in Control Flow (@if, @for, @switch)
- **New**: Template syntax for conditionals and loops
- **Status**: Stable, recommended over *ngIf, *ngFor
- **Migration**: Schematic available
- **Example**:
  ```html
  <!-- Old -->
  <div *ngIf="user">{{user.name}}</div>
  <div *ngFor="let item of items">{{item}}</div>

  <!-- New (recommended) -->
  @if (user) {
    <div>{{user.name}}</div>
  }
  @for (item of items; track item.id) {
    <div>{{item}}</div>
  }
  ```

### Deferrable Views (@defer)
- **New**: Lazy load template sections
- **Benefit**: Better performance, smaller initial bundles
- **Example**:
  ```html
  @defer (on viewport) {
    <heavy-component />
  } @placeholder {
    <p>Loading...</p>
  }
  ```
