# Angular 18 Breaking Changes

> **HttpClient Module System Deprecation** - Major architecture change

## 🔴 CRITICAL Changes

### HttpClientModule Deprecated
- **Deprecated**: `HttpClientModule` in `@angular/common/http`
- **Replace with**: `provideHttpClient()` function
- **Impact**: Build warnings, will be removed in future Angular versions
- **Migration**: Required for all apps using HTTP

**Migration Steps**:

```typescript
// Before (NgModule-based)
import { HttpClientModule } from '@angular/common/http';

@NgModule({
  imports: [
    HttpClientModule
  ]
})
export class AppModule { }

// After (Standalone/Provider-based)
import { provideHttpClient, withInterceptorsFromDi } from '@angular/common/http';

@NgModule({
  providers: [
    provideHttpClient(
      withInterceptorsFromDi() // ⚠️ REQUIRED if using HTTP_INTERCEPTORS
    )
  ]
})
export class AppModule { }

// Or in standalone app
export const appConfig: ApplicationConfig = {
  providers: [
    provideHttpClient(withInterceptorsFromDi())
  ]
};
```

**⚠️ CRITICAL**: If you have existing class-based interceptors using `HTTP_INTERCEPTORS` token, you **MUST** include `withInterceptorsFromDi()` or they won't work!

### HttpClientTestingModule Deprecated
- **Deprecated**: `HttpClientTestingModule`
- **Replace with**: `provideHttpClientTesting()`
- **Impact**: Test failures
- **Migration**:
  ```typescript
  // Before
  import { HttpClientTestingModule } from '@angular/common/http/testing';

  TestBed.configureTestingModule({
    imports: [HttpClientTestingModule]
  });

  // After
  import { provideHttpClientTesting } from '@angular/common/http/testing';

  TestBed.configureTestingModule({
    providers: [provideHttpClientTesting()]
  });
  ```

### HttpClientXsrfModule Deprecated
- **Deprecated**: `HttpClientXsrfModule`
- **Replace with**: `provideHttpClient(withXsrfConfiguration())`
- **Migration**:
  ```typescript
  // Before
  import { HttpClientXsrfModule } from '@angular/common/http';

  @NgModule({
    imports: [
      HttpClientXsrfModule.withOptions({
        cookieName: 'XSRF-TOKEN',
        headerName: 'X-XSRF-TOKEN'
      })
    ]
  })

  // After
  import { provideHttpClient, withXsrfConfiguration } from '@angular/common/http';

  @NgModule({
    providers: [
      provideHttpClient(
        withXsrfConfiguration({
          cookieName: 'XSRF-TOKEN',
          headerName: 'X-XSRF-TOKEN'
        })
      )
    ]
  })
  ```

### HttpClientJsonpModule Deprecated
- **Deprecated**: `HttpClientJsonpModule`
- **Replace with**: `provideHttpClient(withJsonpSupport())`
- **Migration**:
  ```typescript
  // Before
  import { HttpClientJsonpModule } from '@angular/common/http';

  @NgModule({
    imports: [HttpClientJsonpModule]
  })

  // After
  import { provideHttpClient, withJsonpSupport } from '@angular/common/http';

  @NgModule({
    providers: [
      provideHttpClient(withJsonpSupport())
    ]
  })
  ```

## 🟠 HIGH Severity

### HTTP_INTERCEPTORS with provideHttpClient()
- **Issue**: Class-based interceptors using `HTTP_INTERCEPTORS` token won't work without `withInterceptorsFromDi()`
- **Solution**: Add `withInterceptorsFromDi()` to `provideHttpClient()`
- **Alternative**: Migrate to functional interceptors
- **Example**:
  ```typescript
  // Class-based interceptor (existing code)
  @Injectable()
  export class AuthInterceptor implements HttpInterceptor {
    intercept(req: HttpRequest<any>, next: HttpHandler) {
      // Add auth token
      return next.handle(req);
    }
  }

  // Must use withInterceptorsFromDi()
  provideHttpClient(
    withInterceptorsFromDi() // ⚠️ Required!
  )

  // Or migrate to functional interceptor (recommended)
  export const authInterceptor: HttpInterceptorFn = (req, next) => {
    // Add auth token
    return next(req);
  };

  provideHttpClient(
    withInterceptors([authInterceptor]) // ✅ Modern approach
  )
  ```

### Router redirectTo Paths Must Be Absolute
- **Changed**: `redirectTo` must start with `/`
- **Impact**: Routing errors at runtime
- **Example**:
  ```typescript
  // Before (no longer works)
  const routes: Routes = [
    { path: '', redirectTo: 'home', pathMatch: 'full' } // ❌ Error
  ];

  // After (absolute path)
  const routes: Routes = [
    { path: '', redirectTo: '/home', pathMatch: 'full' } // ✅ Correct
  ];
  ```

## 🟡 MEDIUM Severity

### StateKey/TransferState Import Changes
- **Moved**: `StateKey`, `TransferState`, `makeStateKey` moved from `@angular/platform-browser` to `@angular/core`
- **Impact**: Build errors
- **Auto-fix**: ✅ Available
- **Example**:
  ```typescript
  // Before
  import { StateKey, TransferState, makeStateKey } from '@angular/platform-browser';

  // After
  import { StateKey, TransferState, makeStateKey } from '@angular/core';
  ```

### ServerTransferStateModule Removed
- **Removed**: `ServerTransferStateModule` no longer needed
- **Impact**: None - TransferState now automatic
- **Action**: Simply remove the import:
  ```typescript
  // Before
  import { ServerTransferStateModule } from '@angular/platform-server';

  @NgModule({
    imports: [ServerTransferStateModule] // ❌ Remove
  })

  // After - No replacement needed, automatic now
  @NgModule({
    imports: [] // TransferState works automatically
  })
  ```

### platformDynamicServer() Removed
- **Removed**: `platformDynamicServer()` function
- **Replace with**: `renderApplication()` or `renderModule()`
- **Example**:
  ```typescript
  // Before
  import { platformDynamicServer } from '@angular/platform-server';
  platformDynamicServer().bootstrapModule(AppServerModule);

  // After
  import { renderApplication } from '@angular/platform-server';
  renderApplication(AppComponent, { appId: 'my-app' });
  ```

### WebWorker Platform Removed
- **Removed**: `isPlatformWorkerUi()`, `isPlatformWorkerApp()`, `@angular/platform-webworker`
- **Impact**: Build errors if using WebWorkers
- **Action**: Remove WebWorker platform usage

### OnPush Change Detection Behavior
- **Changed**: Root views marked dirty on initialization
- **Impact**: May see extra change detection cycles
- **Action**: Review OnPush components for unexpected behavior

## 🟢 LOW Severity (Recommendations)

### Angular Signals Now Stable
- **Stable**: Signals API is production-ready
- **Recommendation**: Consider migrating from RxJS BehaviorSubject for state management
- **Example**:
  ```typescript
  // Before (RxJS)
  export class MyService {
    private state$ = new BehaviorSubject<State>(initialState);
    state = this.state$.asObservable();

    updateState(value: State) {
      this.state$.next(value);
    }
  }

  // After (Signals - simpler!)
  export class MyService {
    state = signal<State>(initialState);

    updateState(value: State) {
      this.state.set(value);
    }
  }
  ```

### Experimental Zoneless Change Detection
- **Available**: `provideExperimentalZonelessChangeDetection()`
- **Benefit**: Better performance, no zone.js dependency
- **Status**: Experimental in v18, stable in v19+
- **Example**:
  ```typescript
  export const appConfig: ApplicationConfig = {
    providers: [
      provideExperimentalZonelessChangeDetection()
    ]
  };
  ```
