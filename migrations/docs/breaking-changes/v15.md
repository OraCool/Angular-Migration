# Angular 15 Breaking Changes

> **Material Design Components (MDC) Rewrite** - The biggest change in Angular 15

## 🔴 CRITICAL Changes

### TypeScript Target ES2022
- **Required**: TypeScript `target` must be `ES2022` (was `ES2020` in v14)
- **Impact**: Build will fail if not updated
- **Auto-fix**: ✅ Available
- **Migration**: Update `tsconfig.json`:
  ```json
  {
    "compilerOptions": {
      "target": "ES2022"
    }
  }
  ```

### Router relativeLinkResolution Removed
- **Removed**: `relativeLinkResolution` property in RouterModule config
- **Impact**: Build error if present
- **Auto-fix**: ✅ Available
- **Action**: Remove from `RouterModule.forRoot()` calls:
  ```typescript
  // Before
  RouterModule.forRoot(routes, {
    relativeLinkResolution: 'legacy' // ❌ Remove this
  })

  // After
  RouterModule.forRoot(routes)
  ```

### Material Chips API - Complete Rewrite
- **Deprecated**: `mat-chip-list`
- **Impact**: Will break in v17 when legacy components are removed
- **Replace with**:
  - `mat-chip-listbox` + `mat-chip-option` (selectable chips)
  - `mat-chip-grid` + `mat-chip-row` (form input chips)
  - `mat-chip-set` + `mat-chip` (display-only chips)
- **Schematic**: `ng generate @angular/material:mdc-migration`
- **Manual Migration Required**: No auto-fix

**Example - Selectable Chips**:
```html
<!-- Before -->
<mat-chip-list>
  <mat-chip>Chip 1</mat-chip>
  <mat-chip>Chip 2</mat-chip>
</mat-chip-list>

<!-- After -->
<mat-chip-listbox>
  <mat-chip-option>Chip 1</mat-chip-option>
  <mat-chip-option>Chip 2</mat-chip-option>
</mat-chip-listbox>
```

**Example - Form Input Chips**:
```html
<!-- Before -->
<mat-chip-list #chipList>
  <mat-chip *ngFor="let item of items">{{item}}</mat-chip>
  <input [matChipInputFor]="chipList">
</mat-chip-list>

<!-- After -->
<mat-chip-grid #chipGrid>
  <mat-chip-row *ngFor="let item of items">{{item}}</mat-chip-row>
  <input [matChipInputFor]="chipGrid">
</mat-chip-grid>
```

### Material Slider - Complete API Change
- **Changed**: Input/output/thumbLabel properties completely different
- **Impact**: Runtime errors and incorrect behavior
- **Manual Migration Required**: No auto-fix available
- **Schematic**: `ng generate @angular/material:mdc-migration`
- **Documentation**: [Material Slider Migration](https://v15.material.angular.dev/components/slider)

## 🟠 HIGH Severity

### Material Legacy Imports
- **Warning**: `@angular/material/legacy-*` imports will be **removed in v17**
- **Generated by**: MDC migration schematic creates these temporarily
- **Action**: Plan to migrate off legacy components before v17
- **Example**:
  ```typescript
  // Temporary legacy import (after schematic)
  import { MatLegacyButtonModule } from '@angular/material/legacy-button';

  // Must migrate to MDC version before v17
  import { MatButtonModule } from '@angular/material/button';
  ```

### Material Theming - SCSS Module System
- **Deprecated**: `@import '~@angular/material/theming'`
- **Replace with**: `@use '@angular/material' as mat`
- **Impact**: Build warnings, will break in future versions
- **Functions Changed**:
  - `mat-palette()` → `mat.define-palette()`
  - `mat-light-theme()` → `mat.define-light-theme()`
  - `mat-dark-theme()` → `mat.define-dark-theme()`
  - `angular-material-theme()` → `@include mat.all-component-themes()`

**Example**:
```scss
// Before
@import '~@angular/material/theming';
$primary: mat-palette($mat-indigo);
$theme: mat-light-theme($primary, $accent, $warn);
@include angular-material-theme($theme);

// After
@use '@angular/material' as mat;
$primary: mat.define-palette(mat.$indigo-palette);
$theme: mat.define-light-theme((
  color: (primary: $primary, accent: $accent, warn: $warn)
));
@include mat.all-component-themes($theme);
```

### RxJS Subscribe Syntax
- **Deprecated**: `.subscribe(next, error, complete)`
- **Use**: Observer object `{ next, error, complete }`
- **Impact**: Deprecation warnings, will be removed in RxJS 8
- **Example**:
  ```typescript
  // Before (deprecated)
  observable.subscribe(
    value => console.log(value),
    error => console.error(error),
    () => console.log('complete')
  );

  // After (correct)
  observable.subscribe({
    next: value => console.log(value),
    error: error => console.error(error),
    complete: () => console.log('complete')
  });
  ```

### ControlValueAccessor.setDisabledState()
- **Now Required**: Was optional in v14
- **Impact**: TypeScript compilation errors if missing
- **Action**: Implement method if missing:
  ```typescript
  export class MyControl implements ControlValueAccessor {
    // ... other methods ...

    setDisabledState(isDisabled: boolean): void {
      this.disabled = isDisabled;
    }
  }
  ```

## 🟡 MEDIUM Severity

### ag-Grid Import Paths
- **Changed**: Remove `~` prefix from stylesheet imports
- **Impact**: Styling may not load
- **Auto-fix**: ✅ Available
- **Example**:
  ```scss
  // Before
  @import '~ag-grid-community/styles/ag-grid.css';

  // After
  @import 'ag-grid-community/styles/ag-grid.css';
  ```

### Highcharts Type Definitions
- **Changed**: `zoomType` moved from `chart` to `Chart.options`
- **Impact**: TypeScript compilation errors
- **Example**:
  ```typescript
  // Before
  const options: Highcharts.Options = {
    chart: {
      zoomType: 'x' // ❌ Type error
    }
  };

  // After
  const options: Highcharts.Options = {
    chart: {
      options: {
        zoomType: 'x' // ✅ Correct
      }
    }
  };
  ```
