# Angular 16 Breaking Changes

> **Required Inputs, TypeScript 5.0+, Signals Introduction**

## 🔴 CRITICAL Changes

### TypeScript 5.0+ Required
- **Required**: TypeScript `^5.0.0` or higher
- **Impact**: Build failures with older TypeScript versions
- **Action**: Update `package.json`:
  ```json
  {
    "devDependencies": {
      "typescript": "~5.0.0"
    }
  }
  ```

## 🟠 HIGH Severity

### Required Inputs with @Input()
- **New Feature**: `@Input({ required: true })` for mandatory inputs
- **Impact**: Better type safety, but no breaking changes
- **Recommendation**: Add to critical component inputs
- **Example**:
  ```typescript
  @Component({
    selector: 'app-user-card'
  })
  export class UserCardComponent {
    @Input({ required: true }) userId!: string; // TypeScript enforces this
    @Input() showDetails = false; // Optional with default
  }
  ```

### Node.js 16 Support Dropped
- **Removed**: Node.js 16.x support
- **Required**: Node.js 18.13+ or 20.9+
- **Impact**: Build failures with old Node.js
- **Action**: Update Node.js version

## 🟡 MEDIUM Severity

### inject() Function Available in More Contexts
- **Enhancement**: `inject()` can now be used in more places
- **Impact**: None (backward compatible)
- **Benefit**: Better dependency injection patterns
- **Example**:
  ```typescript
  // Now works in more contexts
  const router = inject(Router);
  const activatedRoute = inject(ActivatedRoute);
  ```

## 🟢 LOW Severity (New Features)

### Angular Signals (Developer Preview)
- **New**: Signals for reactive state management
- **Status**: Developer preview in v16, stable in v18
- **Example**:
  ```typescript
  export class CounterComponent {
    count = signal(0);
    doubleCount = computed(() => this.count() * 2);

    increment() {
      this.count.update(n => n + 1);
    }
  }
  ```
